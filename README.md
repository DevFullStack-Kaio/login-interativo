## 📖 Sobre o Projeto

O **Login Interativo** é uma aplicação web desenvolvida para praticar e demonstrar conceitos modernos de autenticação de usuários, integração entre Front-end e Back-end, persistência de dados e experiência do usuário.

A aplicação oferece uma interface dinâmica e responsiva, permitindo cadastro, login e gerenciamento de usuários com validações e feedback visual em tempo real.

---

## 🎯 Objetivos

- Desenvolver um sistema de autenticação completo.
- Aplicar conceitos de Full Stack Development.
- Integrar banco de dados MongoDB.
- Criar uma experiência intuitiva para o usuário.
- Praticar boas práticas de desenvolvimento e organização de código.

---

## 🚀 Funcionalidades

✅ Cadastro de usuários

✅ Login de usuários

✅ Validação de campos

✅ Mensagens de erro e sucesso

✅ Interface responsiva

✅ Persistência de dados no MongoDB

✅ Integração Front-end e Back-end

✅ Navegação intuitiva
